# 问题与改进记录

记录《假装懂 AI》从 0 到上线过程中出现的问题、根因、改善措施与状态。括号内为对应提交号，便于追溯。

当前状态：共记录 16 个问题，已修复 15 个，1 项部分保留。

## 一、产品与交互

### 1. 收藏页看不到内容，原文也打不开

- **现象**：收藏后收藏页空白；点标题进不了详情页
- **根因**：详情页和收藏页从内置 mock 数据里按 ID 查找，线上日报的 ID 是另一套，匹配不上
- **改善**：把 mock 与线上日报合并成统一 itemPool，详情与收藏都从这里查找
- **状态**：已修复（bbf9484）

### 2. 精读与速览看不出区别

- **现象**：两种内容都是白底卡片，用户分不清哪个该细读
- **改善**：精读改为独立卡片 + 左侧靛蓝色条 + 「精读」角标 + 完整概述；速览改为带分隔线的紧凑列表 + 两行截断 + 更小标题
- **状态**：已修复（19365db）

### 3. 页面排版密集、阅读困难

- **现象**：字号偏小、行高紧、装饰元素抢注意力
- **改善**：正文 13→14px、行高 22px；卡片标题 16px；移除 DAILY 水印与状态栏；降低光晕强度；重排区块间距
- **状态**：已修复（bbf9484、19365db）

### 4. 分类不清晰（按来源分）

- **现象**：顶部筛选是"一手官方 / 项目发现"这类**来源类型**，但用户关心的是**内容主题**
- **改善**：改为 7 个内容主题，由大模型在生成卡片时判定；筛选标签同步替换
- **状态**：已修复（19365db）

### 5. 历史日报看不到昨天

- **现象**：历史页只有内置假数据
- **根因**：归档文件每次 CI 都在干净环境重建，前一天的不会带过来；前端也只读 mock
- **改善**：归档与索引随仓库提交；前端新增 useArchive / useDayDigest 读取真实归档
- **状态**：已修复

## 二、内容质量

### 6. 日报内容连续重复

- **现象**：连续两天 8 条里有 7 条一模一样
- **根因**：只取各源最新 N 条，没有"这条是否已发布"的判断
- **改善**：新增已发布索引 `pipeline/data/seen.json`，按 URL 去重，优先只选新内容；工作流每天把索引写回仓库
- **状态**：已修复（e03eb5d）

### 7. 日报条数不足（只出 5 条）

- **现象**：新内容少时只出 5 条
- **根因**：补位阈值设为"少于一半才补"，5 条 ≥ 4 就不补
- **改善**：候选池改为合并新内容与历史内容后统一排序，始终补满 8 条
- **状态**：已修复（b14edbd、edd7344）

### 8. 精读集中在单一来源

- **现象**：3 条精读全部来自 arXiv
- **根因**：最终排序没有做来源轮询
- **改善**：生成后按来源轮询重排，再取前 3 条作为精读
- **状态**：已修复（83eb30a）

### 9. 大模型返回空内容，降级成英文标题

- **现象**：8 条里 3 条标题是英文、概述是套话；单条生成耗时 45 分钟
- **根因**：
  1. 只设了 socket 空闲超时，没有总超时，DeepSeek 高峰期挂住连接
  2. 没有启用 JSON 输出模式，只靠提示词约束
  3. 失败重试 2 次，把 15 分钟放大成 45 分钟
  4. 失败后选择"降级发布"而不是"换内容"
- **改善**：加 60 秒总超时；启用 `response_format: json_object`；重试降到 1 次并加退避；3 路并发；失败直接跳过、换下一条候选；区分"空响应"与"非法 JSON"
- **效果**：同等工作量从 2 小时 15 分降到 12 秒
- **状态**：已修复（b14edbd）

### 10. 信息源覆盖不全（没有国内源）

- **现象**：智谱融资等国内新闻抓不到
- **根因**：原 8 个源全是英文 / 美国视角
- **改善**：新增 12 个源（量子位、新智元、InfoQ 中文、钛媒体、雷峰网、爱范儿、TechCrunch AI、The Verge AI、Ars Technica、Hacker News、MIT Tech Review、Crunchbase News），信息源总数达到 20
- **状态**：已修复（cde5f13、71ee89e）

### 11. 已过窗口的热点抓不到（智谱融资、AI 降速）

- **现象**：用户反馈这两个话题都没收录
- **根因**：每个源只读最新 3-5 条，超出窗口的内容自然抓不到。"AI 降速"实际已被 The Verge AI、新智元、MIT Tech Review 覆盖；智谱融资则已滑出所有中文源的 RSS 窗口
- **改善**：新增钛媒体、雷峰网等行业站点提升覆盖面；把覆盖边界写入 sources.md
- **后续**：接入关键词搜索源（Google News / Bing News RSS）或支持手动提交链接
- **状态**：部分保留

## 三、工程与自动化

### 12. GitHub 未注册工作流

- **现象**：workflow dispatch 返回 404，Actions 列表里没有该工作流
- **根因**：工作流文件缺少文件末尾换行，且含非 ASCII 内容，解析未被注册
- **改善**：工作流改为纯 ASCII 内容并补齐文件末尾换行
- **状态**：已修复（6da1a73）

### 13. Pages 未启用导致部署失败

- **现象**：构建全部成功，只有 configure-pages 步骤失败
- **改善**：通过 API 开启 Pages（build_type = workflow），并在工作流中设置 enablement: true
- **状态**：已修复

### 14. 定时延迟与生成时间漂移

- **现象**：原定早上 8 点的日报，实际凌晨 3 点就生成，早上 8 点的运行反而跳过
- **根因**：
  1. GitHub 的 cron 会排队，实测延迟可达数小时
  2. 守卫只判断"今天是否已生成"，所以北京时间一过午夜，第一次运行就产出了
- **改善**：加"北京时间 08:00 之前不生成"的门控；改为每小时尝试一次，当天已生成则跳过
- **状态**：已修复（b14edbd）

### 15. 排队运行使用旧提交导致重复生成

- **现象**：连续产生两次日报提交
- **根因**：排队的运行 checkout 的是入队时的旧提交，看不到刚生成的归档
- **改善**：checkout 固定 `ref: master`，确保拿到最新提交
- **状态**：已修复

### 16. .env.example 被误忽略

- **现象**：示例配置文件没有进仓库
- **根因**：`.gitignore` 的 `.env.*` 规则把它一起忽略了
- **改善**：增加 `!.env.example` 例外
- **状态**：已修复（7b9593f）

## 五、经验沉淀

1. **先定输出契约，再写 prompt**。字段定下来，前端、管线、模型都可以各自替换
2. **模型的不确定性必须用工程手段兜住**：总超时、重试上限、结构化输出、schema 校验、失败换候选而不是降级发布
3. **决定体验的往往不是模型，而是模型之外的产品逻辑**：去重、排序、时间门控、覆盖边界，这些才是真正让产品可用的部分
