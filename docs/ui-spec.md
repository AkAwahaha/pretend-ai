# 《假装懂 AI》UI 设计规格书

移动端 AI 资讯日报产品 · 可复刻设计规范

## 1. 一句话风格定位

移动端 AI 资讯日报，风格为「温柔科技感」——浅薰衣草底色 + 珊瑚/紫罗兰/粉色的柔光晕染 + 毛玻璃卡片 + 靛蓝品牌色 + 等宽字标签。整体简约、轻盈、有彩色点缀，避免生硬冷峻。

## 2. 画布规格

- 4 张手机竖屏界面，宽度统一 375px
- 状态栏高 62px，导航栏高 44px，底部胶囊 Tab 栏高 83px
- 内容左右边距 16px，卡片间垂直间距 12–20px

## 3. 色彩系统

- 页面底色 #F2F1F6（柔薰衣草灰）
- 卡片底色 #FFFFFF
- 主文本 #17181C
- 次级文本 #5B6472
- 辅助文本 #9AA3AF
- 卡片描边 #ECEEF2
- 品牌/强调色 #5E6AD2（靛蓝）
- 品牌浅底 #EDEFFB

背景光晕（径向渐变 + 大模糊）：

- 珊瑚橘 #FF8A65 → 透明
- 紫罗兰 #A78BFA → 透明
- 粉色 #EC4899 → 透明
- 模糊半径 90–100px，不透明度 0.7–0.8

来源标签专属色：

- OpenAI #0EA371 绿
- GitHub #7C3AED 紫
- Anthropic #F97316 橙
- DeepMind #3B82F6 蓝
- Hugging Face #F59E0B 琥珀
- TLDR AI #EC4899 粉
- a16z #14B8A6 青
- arXiv #EF4444 红

## 4. 字体系统

- 中文正文/标题：Noto Sans SC（Regular / Medium / SemiBold / Bold）
- 英文与数字：Inter（SemiBold / Bold）
- 等宽字（日期、时间戳、来源标签、计数）：JetBrains Mono（Medium / Bold）

字号梯度：

- 首页大标题 36px Bold
- 详情页标题 24px Bold
- 导航标题 17px SemiBold
- 栏目标题 16px SemiBold
- 卡片标题 14–15px SemiBold
- 正文 13px Regular（行高 20）
- 说明/辅助 12px Regular
- 等宽标签 11–12px Mono Medium
- Tab 文字 10px Medium
- 背景水印 140px Bold，不透明度 0.07

## 5. 间距 · 圆角 · 效果

- 间距：8 / 12 / 16 / 20 / 24（8pt 网格）
- 圆角：卡片 16px，列表行 12px，来源标签 6px，胶囊/筛选 chip 999px（全圆）
- 毛玻璃卡片：白色填充不透明度 0.55 + 背景模糊 24px
- 卡片阴影：柔和、低对比，仅在需要悬浮感时使用
- 光晕：径向渐变 + 图层模糊（LAYER_BLUR）90–100px

## 6. 核心组件规格

### ① 来源标签（彩色）

圆角 6 小胶囊，背景用该来源色的浅底（如绿 #E4F7EF），文字用该来源色。精读卡用胶囊；速览/收藏列表用纯彩色文字。

### ② 精读卡片

白底圆角 16，描边 #ECEEF2，内部垂直排列——彩色来源标签 → 15px 标题 → 13px 摘要（2 行）→ 底部一行灰色提示「亮点 · 思路 · 产品视角」。

### ③ 速览行

白底圆角 12，内部：彩色来源文字（Mono 11px）→ 14px 标题 → 12px 摘要（1 行）。

### ④ 筛选 Chip

横向滚动胶囊，选中项靛蓝底白字，未选中白底灰字；容器裁切，最后一个 chip 露出 60% 暗示可滑动。

### ⑤ 底部胶囊 Tab 栏

白底全圆胶囊（圆角 36）内含 3 个 tab（今日/收藏/历史），选中项靛蓝填充 + 白色图标文字，未选中透明 + 灰色。

### ⑥ 彩色玻璃球（首页 Hero 装饰）

84px 圆形，径向渐变「蜜桃高光 → 珊瑚橘 → 紫罗兰 → 薄荷青」四色，左上角叠一个白色柔光小圆点（26px，模糊 7），底部加紫色软投影。

### ⑦ 背景水印文字

超大英文「DAILY」（140px Bold，靛蓝，不透明度 0.07），置于内容层后方。

### ⑧ 三问卡片（详情页）

白底圆角 16，标题前加一个 8px 靛蓝小圆点，标题 15px SemiBold，正文 13px。

## 7. 页面结构

### P1 今日日报（首页）

状态栏 → 品牌头（“假装懂 AI”，AI 用靛蓝 + 09.12 日期胶囊）→ Hero（毛玻璃卡 + 彩色玻璃球 + 36px 大标题「今日 AI 日报」+ 等宽 kicker「DAILY BRIEF」）→ 筛选 chips（全部/一手官方/省时日报/前沿论文/项目发现/商业视角）→ 精读区（3 张彩色标签卡片）→ 速览区（5 条彩色行）→ 底部 Tab 栏。背景叠加珊瑚 + 紫 + 粉三块光晕 +「DAILY」水印。

### P2 内容详情

状态栏 → 导航（返回 + 书签）→ 来源标签 + 24px 标题 + 摘要 → 三问卡片（这是什么 / 核心亮点·实现思路 / 产品视角）→ 来源链接（外链图标 + Mono 链接文字）。

### P3 收藏

状态栏 → 导航（返回 + “收藏”）→ 5 条已收藏项（彩色来源 + 标题 + 靛蓝填充书签）→ 底部 Tab 栏（收藏选中）。

### P4 历史日报

状态栏 → 导航（返回 + “历史日报”）→ 5 条历史日期（Mono 日期 + 摘要 + 右箭头）→ 底部 Tab 栏（历史选中）。

## 8. 复刻时的关键要点

1. 底色别用纯白，用带一点紫调的浅灰 #F2F1F6，这是“温柔感”的来源。
2. 光晕必须大而模糊，且放在内容最底层，卡片要浮在光晕之上（毛玻璃或白卡留白透出光晕）。
3. 来源一定要彩色区分，这是“生动有趣”的核心，8 个来源 8 种颜色。
4. 科技感靠等宽字 + 靛蓝 + 玻璃球，不要用深色底或霓虹，保持“轻”。
5. 一个页面一个主视觉：首页有玻璃球 + 水印，其余页面靠彩色标签 + 光晕即可，避免堆砌。
